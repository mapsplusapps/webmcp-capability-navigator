# Hackathon provenance

Capability Navigator's WebMCP product layer was built during the WebMCP Challenge submission period, August 25–September 3, 2026.

Pre-existing Maps + Apps material is limited to public portfolio/capability evidence about prior work. The challenge-specific implementation includes the typed `document.modelContext.registerTool(...)` browser contract, six bounded tools, deterministic capability matching and packet preparation, visible agent trace, same-page human review staging, ordinary-browser fallback, origin-isolation deployment headers, judge path, and release verification.

The public repository commit history timestamps the challenge-period source additions. The evidence records remain claims about prior Maps + Apps work; the WebMCP interaction layer is new challenge work.
